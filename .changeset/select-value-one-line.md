**Visible change — select.** A long value now stays on one line, cut with « … », instead of taking two lines: a select keeps the height of the fields beside it (38px). The whole label is still in the tooltip and the list. The value takes a zero base width and grows, so a long value does not widen the select, its grid track or the page on a phone. A multi-select's chips still wrap, so no choice is hidden.
