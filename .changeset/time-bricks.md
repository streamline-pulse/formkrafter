**Appointments and periods.** `appointment` lets the user pick a slot
(`{ id, start, end }`) day by day in a new `fk-slot-picker` element; slots come
from `slotsUrl` (a list with `remaining` counts, read by `readSlots`) or are
generated by `generateSlots` from the opening rules set in the builder (days,
hours, duration, horizon, notice, closed dates). `date-range` stores
`{ from, to }` and the schema refuses an end before the start (`dateRange`
keyword). New `Time` category; the native renderer edits the range and shows
the chosen slot.
