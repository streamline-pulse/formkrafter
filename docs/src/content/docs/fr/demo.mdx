## Playground — dans cette page

C'est le vrai `<fk-form-builder>`, chargé depuis le package que vous installeriez — pas une vidéo, pas une maquette. Glissez des bricks depuis la palette, cliquez sur l'une d'elles pour éditer ses configs, validations, styles et règles, utilisez undo/redo, et exportez le JSON avec le bouton Copy.

<LiveDemo mode="builder" />

:::tip
Le builder émet un événement `specChange` à chaque modification, avec le nouveau spec **et** des patches RFC 6902 dans les deux sens — persistez-les, synchronisez-les, ou alimentez `<fk-form-render>` en direct comme dans [bien démarrer](/formkrafter/fr/getting-started/).
:::
