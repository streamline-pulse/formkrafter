Lire un article sur un form builder a ses limites. Cette page fait tourner le
composant réel — celui que vous récupérez depuis npm — et renvoie vers des
applications complètes qui le montrent branché dans une vraie stack.

## Playground — directement dans cette page

C'est le vrai `<fk-form-builder>`, chargé depuis le package que vous
installeriez : pas une vidéo, pas une maquette. Glissez des bricks depuis la
palette, cliquez sur l'une d'elles pour éditer ses configs, validations, styles
et règles, utilisez undo/redo, et exportez le résultat avec le bouton Copy.

<LiveDemo mode="builder" />

<Aside type="tip">
Chaque édition émet `specChange` avec le nouveau spec **et** des patches
RFC 6902 dans les deux sens — persistez-les, synchronisez-les, ou alimentez
`<fk-form-render>` en direct comme dans [bien démarrer](../getting-started/).
</Aside>
