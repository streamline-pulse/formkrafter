showing it wired into a real stack.

## Playground — right in this page

This is the real `<fk-form-builder>`, loaded from the package you would install:
not a video, not a mock. Drag bricks from the palette, click one to edit its
configs, validations, styles and rules, use undo/redo, and export the result
with the Copy button.

<LiveDemo mode="builder" />

<Aside type="tip">
Every edit emits `specChange` with the new spec **and** RFC 6902 patches in both
directions — persist them, sync them, or feed `<fk-form-render>` live as shown
in [getting started](getting-started/).
</Aside>
