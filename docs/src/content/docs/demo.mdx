This is the real `<fk-form-builder>`, loaded from the same package you would install — not a video, not a mock.

Drag bricks from the palette, click one to edit its configs, validations, styles and rules, use undo/redo, and export the JSON with the Copy button.

<LiveDemo mode="builder" />

:::tip
The builder emits a `specChange` event on every edit with the new spec **and** RFC 6902 patches in both directions — persist them, sync them, or feed `<fk-form-render>` live as in [getting started](/formkrafter/getting-started/).
:::
